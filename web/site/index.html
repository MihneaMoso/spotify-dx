Spotify DX

A Spotify client for desktop and mobile that feels like open.spotify.com: the real Spotify login in-app, sessions that persist, and full-track playback for free accounts too.

Open the web app Install on your device View on GitHub

Sign in the way the web does

The app opens the real Spotify login page in-app — password, 2FA, passkeys all work. Your session cookies persist, so you stay logged in across restarts.

Playback for everyone

Premium accounts use the official Web Playback SDK. Free accounts get an open multi-source engine — full tracks, not just 30-second previews.

Ad-free listening

An in-process AdGuard blocklist engine drops third-party ad and tracker requests before they hit the network.

Install the latest release

One command fetches the newest release and installs it safely: 

curl -fsSL https://raw.githubusercontent.com/MihneaMoso/spotify-dx/master/install.sh | bash

Desktop installs to ~/.local/bin/spotify-dx. On Android it downloads the APK to your Downloads folder. Every download is verified against its SHA-256 digest.
